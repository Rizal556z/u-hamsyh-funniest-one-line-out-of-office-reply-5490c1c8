## Entry

> I'm away until Monday, doing nothing in a place my boss can't pronounce.

(72 characters)

## Why this line works

It keeps the exact shape of a real out-of-office message — away until Monday — and then quietly breaks it: instead of the usual beach, inbox, or "limited access" excuse, the holiday is spent doing nothing somewhere the boss cannot even pronounce. The laugh lands on the first read because the setup is the familiar away notice itself and the punchline is a small, relatable rebellion, the kind of line a colleague forwards to a friend rather than deletes.

## How it works

`main.py` (pure Python standard library, no network, no secrets) writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), creating the output directory if needed. Before writing, it validates the gate: the text is 1–160 characters, a single line, valid UTF-8, and has no leading or trailing whitespace. Run it with `python3 main.py`.
